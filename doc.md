### Min Error Boundary
Min Error Boundary komponent är designad för att fånga oväntade fel i applikationen och visa ett användarvänligt gränssnitt istället för att låta hela applikationen krascha. Jag hade sedan innan en Error Alert komponent, den har jag även återanvänt i min Error Boundary för att visa felmeddelande. Genom att använda getDerivedStateFromError uppdateras komponentens state så om ett fel uppstår, visas min specialdesignade vy - som matchar resterande sida. Jag har placerat min ErrorBoundary runt App i main.tsx, för att kunna skydda hela applikationen. Detta förbättrar upplevelsen på sidan genom att användaren får en tydlig förklarning:("Ett oväntat fel uppstod, försök ladda om sidan eller gå tillbaka till startsidan") därefter finns det möjligheter att antigen ladda om sidan, eller gå tillbaka till startsidan. 

### Min återanvändningsbara komponent 
Jag valde att göra en ny komponent som återanvändingsbar, Modal.tsx. Syftet är att använda en dialog som kan visas ovanpå applikationens innehåll, så att till exempel villkorstext, formulär, bekräftelser kan återanvändas enklare utan att duplicera logik för stänging, tangentbordsinteraktion eller scroll låsning. I detta projekt används denna komponent just nu i Terms.tsx när man vill visa användarvillkor men den kan även användas i till exempel AddToLog.tsx. Detta gör också att komponenten skulle kunna flyttas till andra projekt.  

### Data och statehantering
Jag valde att inte ha något exernt paket för state hantering utan jag använde istället Reacts inbyggda Context API. Med Context behöver jag inte skicka props mellan flera komponenter, vilket gör koden enklare. I mitt projekt använder jag detta genom att jag skapat en AuthContext i mappen Context. Där sparas användaren tillsammans med funktionerna login och logout. Jag har även wrappat hela appen med AuthProvider i main.tsx så att komponentner kan nå state med useAuth. LoginForm uppdaterar context när en användare loggar in, NavBar läser state för att visa rätt meny och LoggedInUser hämtar användare för att visa information + hälsologg.
